# 硬件接线图（STM32F103C8T6 数据采集节点）

> 适用主控：STM32F103C8T6 最小系统板（72MHz，12 位 ADC，3.3V 逻辑）
> 传感器：DHT11 温湿度、ACS712-20A 电流互感器、100k/4.7k 分压电阻测电压
> 外设：SSD1306 OLED（I2C）、ESP-01S（ESP8266）、蜂鸣器、继电器、三按键

---

## 1. 总体连接框图

```
                       ┌────────────────────────────────────────────┐
                       │        STM32F103C8T6 最小系统板             │
                       │                                            │
  DHT11 DATA ──────────┤ PA0          PA9/TX1 ──── USB转TTL(调试)  ├──── 调试PC
  ACS712 OUT ──────────┤ PA1/ADC1     PA10/RX1 ──── USB转TTL(调试) │
  分压采样点 ───────────┤ PA4/ADC4     PA2/TX2 ──── ESP8266 RX      │
  OLED SCL ────────────┤ PB6          PA3/RX2 ──── ESP8266 TX      │
  OLED SDA ────────────┤ PB7          PA8 ──────── 继电器 IN       │
  蜂鸣器 + ────────────┤ PB0          PB10 ─────── KEY_MENU        │
                       │              PB11 ─────── KEY_UP           │
  GND(公共地) ──────────┤ GND          PB12 ─────── KEY_DOWN        │
                       │ 3.3V/5V ──── 电源输入                      │
                       └────────────────────────────────────────────┘
```

## 3. 各模块接线详解

### 3.1 DHT11 温湿度传感器（3.3V 供电）

```
 DHT11                         STM32
 ┌─────────┐
 │ VCC ────┼──────────────────► 3.3V        (1脚)
 │ DATA ───┼───────┬──────────► PA0         (2脚)
 │ NC ─────┼─ 悬空 │                        (3脚)
 │ GND ────┼───────┼──────────► GND         (4脚)
 └─────────┘       │
              4.7kΩ 上拉电阻至 3.3V
```

接线要点：
- DATA 必须加 **4.7kΩ 上拉**（裸模块若已带上拉可不接）；
- 线长超过 1m 时改用**屏蔽线**，屏蔽层单端接 GND，否则读取校验和易出错。

### 3.2 ACS712-20A 电流互感器模块

```
  被测负载回路(串入 IP+ → IP-)        ACS712 模块            STM32
 ┌──────────┐    ┌──────────────────────────────┐
 │  +24V ───┼────┤ IP+                      VCC ├────────► 5V
 │           │    │                              │
 │  负载 ────┼────┤ IP-                  FILTER ├──┐
 └──────────┘    │                              │  │
                 │                       OUT ───┼──┴─────► PA1 (ADC1_IN1)
                 │                            GND├────────► GND
                 └──────────────────────────────┘
```

接线要点：
- IP+/IP- 串接在被测负载的**火线/正极回路**，方向任意（双向测量）；
- OUT 输出 2.5V±0.1V/A，零点漂移由程序上电自校准消除；
- OUT 对地并联 **100nF + 10uF** 滤波电容（部分模块已含 RC）；
- ⚠️ IP 回路与 MCU 无电气隔离问题（ACS712 为霍尔隔离），但 IP 端子带电，务必断电接线。

### 3.3 分压电阻测电压（0~30V DC 量程）

```
   被测母线 +V (最高30V)
        │
      [ R1 = 100kΩ 1% 精密电阻 ]
        │  ←── 分压中点(≈V×0.0449, 30V时≈1.35V, 安全<3.3V)
        ├────────────────► PA4 (ADC1_IN4)
        │
      [ R2 = 4.7kΩ 1% 精密电阻 ]
        │
   3.3V 稳压二极管(保护, 反向并联: 中点对地)
        │
       GND (与被测电压共地!)
```

接线要点：
- 分压比 = (100+4.7)/4.7 ≈ **22.28**，程序中 `V_DIV_RATIO` 与此对应；
- 中点**必须**加 3.3V 稳压管钳位 + 100nF 对地滤波，防止浪涌打穿 ADC；
- ⚠️ 仅适用于**与 MCU 共地**的直流母线；如需测交流或隔离回路，请改用 ZMPT101B（电压互感模块）；
- R1/R2 用 1% 精密电阻，普通 5% 电阻会造成约 ±1V 测量误差。

### 3.4 OLED 显示屏（SSD1306，I2C）

```
 OLED (0.96寸)                    STM32
 ┌───────────┐
 │ GND ──────┼───────────────► GND
 │ VCC ──────┼───────────────► 3.3V
 │ SCL ───┬──┼───────────────► PB6
 │        │  │
 │ SDA ──┬┴──┼───────────────► PB7
 └───────┼──┘
        4.7kΩ×2 上拉至 3.3V
```

I2C 地址：0x78（8 位写地址），软件位带模拟，时钟约 100kHz。

### 3.5 ESP8266（ESP-01S，MQTT 上传）

```
 ESP-01S                         STM32
 ┌────────────┐
 │ VCC ───────┼────► 3.3V (独立 AMS1117-3.3, ≥300mA)
 │ GND ───────┼────► GND
 │ TX  ───────┼────► PA3 (USART2_RX)
 │ RX  ───────┼────► PA2 (USART2_TX)   ←⚠ 电平同为3.3V, 无需分压
 │ CH_PD ─────┼────► 3.3V (10kΩ 上拉)
 │ RST  ──────┼────► 3.3V (10kΩ 上拉, 可接PB5做程序复位)
 │ GPIO0 ─────┼────► 3.3V (运行AT固件, 悬空烧录)
 └────────────┘
```

接线要点：
- ESP8266 发射瞬间电流可达 **300mA**，与 STM32 共用 LDO 会引起 3.3V 跌落导致复位/断连，**必须独立供电**并就近并联 **470uF 电解 + 100nF 陶瓷**（调试记录 Day9 的断连根因）。

### 3.6 按键 / 蜂鸣器 / 继电器

```
 3.3V                            5V
  │ (内部上拉)                     │
  ├──[KEY_MENU]──► PB10           ├── 继电器模块 VCC
  ├──[KEY_UP]────► PB11           │    IN ◄──────── PA8
  └──[KEY_DOWN]──► PB12           │    COM/NO ──► 负载电源回路(联锁切断)
                                  │
  5V ── 蜂鸣器+ ── 蜂鸣器- ──► NPN(C8050)集电极
                     基极 ──[1kΩ]──► PB0
                     发射极 ──────► GND
```

## 4. 电源接线

```
 220V AC ──► 24V/1A 开关电源 ──┬──► 继电器模块(5V经7805)
                              ├──► AMS1117-5.0 ──► 蜂鸣器
                              └──► AMS1117-3.3 #1 ──► STM32 / OLED / DHT11
                                   AMS1117-3.3 #2 ──► ESP8266 (独立供电!)
 全部 GND 在电源入口处单点汇接（星形接地），模拟地与数字地磁珠隔离
```

## 5. 抗干扰与安全注意事项

1. **单点接地**：传感器信号地、电源地、模块地在电源入口星形汇接，避免地环路引入 ADC 跳变；
2. **屏蔽线**：DHT11 与 ADC 信号线超过 0.5m 使用屏蔽双绞线，屏蔽层**单端**接地；
3. **去耦**：每个 IC 电源脚就近 100nF；ACS712 OUT 加 10uF+100nF；ESP8266 加 470uF；
4. **强电隔离**：ACS712 的 IP 端子虽隔离，但接线必须**断电操作**；继电器触点接负载时加 RC 吸收支路（47Ω+0.1uF）；
5. **禁止**用分压电阻直接测量 220V AC 或不共地回路。
