# 项目总结（第一人称）

在我负责的智能工厂数据采集系统项目中，我完成了单片机编程、Python 看板开发和现场接线调试的全流程工作，实现了车间温湿度、电流、电压的实时采集与 Web 监控。

单片机方面，我基于 STM32F103C8T6 编写采集程序：实现 DHT11 单总线时序、ADC 采集 ACS712 电流与分压电压、OLED 本地显示、按键阈值设置与 Flash 掉电保存，以及蜂鸣器继电器报警。针对电流曲线周期性跳变，我用示波器定位到变频器干扰，设计了中值滤波加滑动平均算法，配合屏蔽线和单点接地整改，将跳变彻底降为零；针对 ESP8266 供电跌落导致的周期性断连，采用独立供电加储能电容方案，并实现自动重连与遗嘱离线感知；针对感性负载启动浪涌造成的阈值误报，设计了三次连续确认加迟滞回差判定，使误报降为零。

上位机方面，我用 Python 开发监控看板：paho-mqtt 订阅设备数据，Flask 提供 REST 接口，ECharts 绘制实时曲线与电流仪表盘，pandas 完成统计分析与 CSV 导出，并支持网页远程下发阈值命令。

现场调试中，我独立完成电气柜布局规划、端子接线与强弱电分离接地施工，历经十五天调试逐一攻克数据跳变、通信断连、阈值误报三大问题，系统通过二十四小时拷机与产线验收。项目让我打通了感知、网络、应用三层完整物联网链路，锻炼了跨软硬件与电气边界定位问题的系统能力。
