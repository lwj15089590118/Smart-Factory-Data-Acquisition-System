# 操作说明书

> 适用产品：Smart-Factory-Data-Acquisition-System（智能工厂数据采集系统）V1.2
> 适用人员：产线操作工（第 3~5 章）、电气维护人员（第 2、6 章）
> ⚠ 安全提示：柜内存在 220V AC 强电，非电气人员请勿打开柜门！

---

## 1. 系统组成速览

| 部分 | 位置 | 作用 |
|------|------|------|
| 采集节点（STM32+OLED） | 车间采集柜 | 采集温湿度/电流/电压，本地显示与报警 |
| ESP8266 通信模块 | 采集柜内 | 将数据经 WiFi 上传 MQTT 服务器 |
| Web 看板 | 服务器/任意浏览器 | 实时曲线、报警事件、阈值设置、导出报表 |

## 2. 开机顺序（务必按序执行）

1. **检查**：确认柜门关闭、观察窗完好；确认 X1 端子 L/N/PE 无松动；确认负载回路无短路；
2. **空载上电**：合上柜内断路器 QF1 → 电源指示灯亮，**保持负载断开 3 秒**（系统进行电流零点自校准，期间蜂鸣器短响一声表示自检通过）；
3. **启动上位机**：服务器上执行 `python dashboard.py --broker <Broker地址>`（正常应已配置为开机自启）；打开浏览器访问看板地址（如 `http://192.168.1.50:5000`）；
4. **确认在线**：看板右上角显示 "● MQTT已连接"，节点 OLED 第 5 行显示 `NET:OK`；
5. **投入负载**：合上负载回路，观察看板电流曲线正常、无报警后完成开机。

> 关机顺序与之相反：先断负载 → 再断 QF1 → 最后停上位机服务。

## 3. 参数设置

### 3.1 现场按键设置（柜门旁三按键）

| 按键 | 短按（<1s） | 长按（>1s） |
|------|-------------|-------------|
| MENU（S1） | 依次切换：运行 → 温度上限 → 电流上限 → 电压上限 → 电压下限 → 返回运行（返回时自动保存，蜂鸣器响一声） | — |
| UP（S2） | 当前参数 +0.1 | 当前参数 +1.0 |
| DOWN（S3） | 当前参数 -0.1 | 当前参数 -1.0 |

OLED 设置界面示例：`SET CurrMax =11.5` 表示正在调整电流上限。

**默认阈值**：温度上限 40.0°C；电流上限 10.0A（按负载额定值调整，建议设为额定的 1.2~1.35 倍）；电压上限 30.0V / 下限 20.0V。

### 3.2 看板网页设置

看板右上"阈值设置"区域填入数值 → 点击【下发】→ 节点回执后立即生效并 Flash 保存（掉电不丢）。看板修改会记录在事件表中，便于追溯。

## 4. 报警显示与处理

### 4.1 报警表现

- 现场：蜂鸣器连续鸣响，OLED 显示 `** ALARM **`，联锁继电器动作（仅电流持续越限切负载）；
- 看板：曲线红色越限区、事件表出现 ALARM 记录。

### 4.2 报警处理流程（三步法）

```
 听到/看到报警 → 先按处理表处置 → 处置后按 MENU 短按可消音,
 报警条件未消除前蜂鸣器每 60s 提示一次; 条件消除后自动复位
```

| 报警类型 | 常见原因 | 处理措施 |
|----------|----------|----------|
| 温度越限（alarm=1） | 环境温度过高/设备过热 | 检查现场通风与被测设备；确认后调高阈值需工艺批准 |
| 电流越限（alarm=2） | 过载、堵转、短路 | **立即检查负载**；若电机刚启动属正常暂态（系统已自动忽略 6 秒内冲击），持续报警则停机检修 |
| 电压越限（alarm=4） | 电源故障、线路压降 | 测量母线电压；低于下限检查接线端子是否氧化松动 |
| 看板显示"设备离线" | WiFi/Broker/供电故障 | 见 6.2 故障排查表 |

⚠ **任何时候不得通过拔线、断电的方式"消除"报警**；继电器联锁切断的负载必须查明原因后方可再投入。

## 5. 日常维护

| 周期 | 项目 | 方法 | 判定标准 |
|------|------|------|----------|
| 每班 | 看板曲线巡视 | 打开看板确认曲线连续 | 无跳变、无离线 |
| 每班 | 报警音测试 | 按下 TEST 键（柜门，选配） | 蜂鸣器鸣响 |
| 每周 | 端子紧固检查 | 断电后逐个检查 X1~X3 端子 | 无松动、无烧蚀发黑 |
| 每周 | 数据导出备份 | 看板"导出 CSV"归档 | 文件可打开、条数≥10 万/周 |
| 每月 | 接地检查 | 接地电阻表测 PE | < 4Ω |
| 每月 | 温湿度计比对 | 标准温湿度计对比 DHT11 | 偏差 ≤ ±3°C / ±5%RH，超差更换传感器 |
| 每季 | 电流电压表比对 | 钳形表对比看板读数（稳态负载） | 偏差 ≤ ±3%，超差重新校准零点 |
| 每半年 | 清灰 | 干燥压缩空气吹扫柜内 | 无积尘，散热孔通畅 |

## 6. 常见故障排查

### 6.1 现场侧

| 故障现象 | 可能原因 | 处理 |
|----------|----------|------|
| OLED 黑屏 | 供电/I2C 松脱 | 检查 3.3V 与 PB6/PB7 排线 |
| 温湿度显示 -99.9 | DHT11 损坏或线断 | 换传感器（断电插拔） |
| 空载电流不为 0 | 零点漂移 | 断负载重启重新自校准 |
| 蜂鸣器长鸣不停 | 报警未消除或继电器粘连 | 按 4.2 处理；仍长鸣则更换继电器模块 |

### 6.2 通信侧

| 故障现象 | 可能原因 | 处理 |
|----------|----------|------|
| OLED 显示 NET:-- | WiFi 断开/Broker 停止/供电不足 | 等待 30s 自动重连；检查路由器与 Broker 服务；检查 ESP8266 供电（470uF 电容是否脱落） |
| 看板"设备离线"但 OLED 显示 NET:OK | 看板与 Broker 断连 | 重启 dashboard.py；检查服务器网络 |
| 曲线偶发跳变 | 强干扰/屏蔽层脱落 | 检查屏蔽层接地；对照调试记录 Day4 措施复查走线 |

## 7. 保修与技术支持

- 传感器（DHT11/ACS712）属易损件，建议每 12 个月预防性更换；
- 技术支持：SmartFactory 项目组（内部工单系统）。
